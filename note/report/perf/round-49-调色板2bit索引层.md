# 轮次 49：调色板第三层——≤4 态 2 bit 索引存储

**日期**：2026-10-13 · **主题**：内存占用（区块方块存储，轮 5 直系续作） · **结论**：正向优化，已收编

## 动机

区块方块数据是服务端最大的常驻内存面（24 区段/区块 × 数千加载区块）。轮次 5 建立的存储阶梯为：同质（零堆）→ 半字节索引（≤16 态，2048B/区段）→ u8 索引（≤256 态，4096B）→ 稠密值。侦察确认 2-4 态低多样性区段（空气+洞穴贯通段、水体、岩层过渡带）与 16 态区段同价——**第三层 2 bit 索引**（每字节四格，1024B）可把该带宽的索引存储砍半。轮次 48 后实体/方块实体侧已到结构地板，区块存储是剩余最大的杠杆。

## 改动

`crates/papokin-world/src/chunk/palette.rs`（`PaletteStorage` 为文件私有枚举，约 20 处触点全部在单文件内收口）：

- 新增 `Packed2(Box<[u8]>)` 存储变体（缓冲区长度恒 `VOLUME/4`：方块区段 1024B、群系区段 16B）与 `packed2_get/packed2_set` 2 bit 访问器；
- 四条构建路径统一加层：`from_cube` / `from_fn` / `from_palette_and_packed_data`（磁盘反序列化）在 ≤4 态优先落 Packed2；`get` / `iter` / `to_palette_and_packed_data`（网络序列化）各加对应分支；
- 升级链 `Packed2 → Nibble → Indexed → Dense` 单调完备：`set` 时调色板超过 4 态触发 `upgrade_packed2_to_nibble`，展开走 256 项查找表（每源字节一次查表得两个半字节字节，比逐格位移写少 3/4 操作数）；
- 计数归零的 swap_remove 索引改写在 Packed2 层镜像 Nibble 语义；
- 存储升级体抽为 `upgrade_packed2_to_nibble` / `upgrade_nibble_to_indexed` 两助手（`set` 行数房规）。

测试：3 态三构建路径断言改判 Packed2 层；新增 5 态 Nibble 层三路径断言、`packed2_upgrades_to_nibble_at_five_states` 升级边界测试；3 态降级同质测试更名归层。18 项调色板测试全绿。

## 基准（`benchmark/src/bin/palette_packed2.rs`）

双臂：旧臂基准内忠实复刻改动前语义（Homogeneous / Nibble ≤16 / Indexed ≤256 / Dense，含同质升级的 O(VOLUME) 展平成本与 Indexed→Dense 升级链）；新臂直接用生产 `BlockPalette`。语料 2400 区段按自然地形调色板尺寸分布（55% 同质 / 17% 2-4 / 8% 5-8 / 12% 9-16 / 6% 17-64 / 2% 65-300），逐次变异构建。

| 闸门 | 结果 |
| --- | --- |
| 全量迭代+变异指纹全等（主语义） | √ 双臂一致 |
| 网络三元组指纹全等（位宽/调色板/打包字） | √ 双臂一致（对齐 Single/Indirect/Direct 三层语义折叠） |
| 存活字节下降（主判据） | √ 2957408 → 2514016 B（净差 443392 B；2-4 态带 433 区段每区段恰 −1024B） |
| 稳态写电池不劣化（≥0.91×，4 趟稳测量） | √ 16.90 → 17.22 ms（×0.981） |

迁移相如实登记（非闸门）：13.38 → 24.61 ms——同质/低态区段被灌入 5+ 新态时的一次性 Packed2→Nibble 升级为设计内成本（每区段每生命周期一次 O(VOLUME)，LUT 化后已从 30.19ms 压至 24.61ms）；世界生成的批量构建路径（from_fn/from_cube）直接选层、不走升级。构建 ×1.02。原始数据见 `round49-palette-packed2.json`。

## 排障记录（基准方法论）

本轮基准三次闸门失败均为复刻保真度问题而非生产缺陷，修复过程有普遍价值：

1. **旧臂网络折叠未分层**：对同质段按间接层折叠（位宽 4）、对 65-300 态段漏判 Direct 层——对齐生产 `convert_network` 三层语义后通过；
2. **位宽语义复刻错误**：`floor(log2(n))` ≠ `encompassing_bits`（后者为 ilog2 + 非二次幂进位），≤16 态被 min-4 掩蔽、17+ 态暴露——分带指纹定位后修正；
3. **电池成本不对称**：旧臂同质升级走 O(1) 捷径而生产走 O(VOLUME) from_cube，且生产臂每次 set 做注册表校验——补齐展平成本、预换算状态池后公平；
4. **稳态 ×0.890 悬案**：迟到升级（稳态首趟才触发 Packed2→Nibble 的区段）所致，升级路径 LUT 化后 ×0.981 达标——先优化再复测，而非改判据。

## 语义与风险

- 2 bit 索引与半字节索引同为「调色板内序 → 打包位」的纯表示变换，四条构建路径与读写/序列化全路径指纹全等兜底；
- 网络序列化位宽只由调色板长度决定（min 4 bit 映射下界），Packed2 不改变任何线上字节；
- 升级为单向（计数归零不降存储层），与既有 Nibble/Indexed 行为一致。
