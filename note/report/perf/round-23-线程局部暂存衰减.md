# 轮次 23：线程局部暂存的用后容量衰减

> 日期：2026-10-04 ｜ 主题：内存（驻留容量） ｜ 闸门：5/5 PASS
> 基准：[benchmark/src/bin/thread_local_scratch_decay.rs](../../../benchmark/src/bin/thread_local_scratch_decay.rs)
> 数据：[round23-thread-local-scratch-decay.json](round23-thread-local-scratch-decay.json)

## 问题

轮次 16/17 把碰撞收集与按盒查询改为线程局部暂存（`RefCell<Vec>`），
消去了逐调用分配；但这些 `Vec` 只在使用起点 `clear` 重填、**从不
收缩**：任何一次尖峰填充（复杂地形的实体移动碰撞收集、密集区大盒
查询）的容量都随线程永久驻留。受影响面 =  rayon 工作线程（限容
`(核数/4).clamp(4,8)`）+ 途经这些调用点的 tokio 任务线程，每线程
各自驻留一份自身历史峰值。轮次 20 的衰减治理覆盖了 tick 边界的
16 处清理点，线程局部暂存不在其列（无 tick 边界钩子）——本轮
补齐这最后一个未管理的可增长缓冲族。

侦察中已确认边界（如实记录，防重复探查）：
- `DENSITY_BUFFER_POOL`（`density_volume.rs`）：`Box<[f32]>` 池，
  `MAX_POOLED_BUFFERS = 1024` 硬上限，有界不立项；
- biome `LAST_RESULT_NODE`、datapack 三个 `Cell` 标量：无堆容量；
- 出站队列：`MAX_PENDING_BYTES = 64 MB` 字节记账 + 溢出断连
  （`try_enqueue_packet_data`），有界不立项。

## 机制

在四个消费点（`world/mod.rs`）的消费闭包返回后、借用结束前，
按**本轮填充量**执行轮次 20 原语 `decay_clear_vec`：

1. `get_block_collisions`（:2400）：`collisions` + `positions` 双暂存；
2. `with_entities_at_box`（:4073）；
3. `with_players_at_box`（:4086）；
4. `with_entities_and_players_at_box`（:4100）。

语义与安全论证：
- `decay_clear_vec` 先取 `last_len`（= 本轮填充数）再清理——滞回
  判定锚定本轮真实用量，而非下一拍起点（起点 `len` 恒为 0，
  会退化为每拍收缩、丢失跨调用复用收益）；
- 尖峰当拍**不**收缩（本轮 `last_len` = 尖峰量，4× 滞回包含之），
  尖峰后第一个稳态调用即回落至 `last_len + 64`；稳态段
  `capacity ≤ 4 × len` 恒成立，零收缩抖动；
- 消费闭包 `f` 在衰减之前执行完毕，`f` 所见切片内容不受任何
  影响（指纹闸门实证）；
- 无重入路径（既有文档化约束：`RefCell` 借用不跨出单次收集，
  消费不回调本收集），衰减在借用作用域内、无跨线程可见性。

## 负载模型

8 模拟线程 × 600 tick：每线程每 tick 碰撞收集（24B 形状项 +
16B 位置项）稳态 32 项、按盒查询（8B 项）稳态 48 项；第 10 tick
每线程各一次尖峰（碰撞 8192 / 按盒 4096，复杂地形或密集区大盒）。
两臂：无衰减（起点 `clear`）vs 用后衰减（`decay_clear_vec`）。

## 结果

| 指标 | 无衰减 | 衰减 | 差值 |
| --- | ---: | ---: | ---: |
| 尖峰后一拍驻留（8 线程合计） | 2,883,584 B | 37,888 B | **76.1× 回收** |
| 收尾驻留 | 2,883,584 B | 37,888 B | 76.1× |
| 全程分配次数 | 200 | 224 | +24 |
| 收缩事件 | 0 | 24（8 线程 × 3 缓冲各一次） | 第 100 tick 后 0 次 |

- 尖峰（碰撞 8192 项 + 按盒 4096 项/线程）当拍：两臂驻留一致
  （衰减臂的 4× 滞回包含本轮尖峰量，当拍不收缩）；
- 尖峰后第一个稳态调用：衰减臂三缓冲全部回落至 `last_len + 64`
  （每线程约 4.7 KB），此后 589 tick 零收缩——无衰减臂把
  每线程约 360 KB 的尖峰容量驻留到线程退出；
- 代价：每线程每缓冲各一次收缩重分配（8×3 = 24 次，全程占比
  12%），稳态段分配两臂完全一致；
- 消费指纹全等（`0xb1fa…58ca`）：`f` 所见切片内容不受衰减影响。

## 闸门

| 闸门 | 结果 | 说明 |
| --- | --- | --- |
| 消费指纹全等（非退化） | PASS | `0xb1fa838b50bd58ca` 双臂一致 |
| 尖峰后驻留 ≥4× 回收 | PASS | 实测 76.1× |
| 收尾驻留 ≥4× 回收 | PASS | 实测 76.1×（尖峰零驻留化） |
| 收缩有界且稳态零收缩 | PASS | 24 次 = 8 线程 × 3 缓冲，第 100 tick 后 0 |
| 额外分配 ≤64 | PASS | 实测 +24 |

## 结论与后续

收编：四个消费点各加一行（碰撞点双缓冲两行），复用轮次 20 既有
原语零新机制，换来尖峰容量 76.1× 的随线程驻留回收，语义零变化
（指纹全等、papokin 411 全绿）。至此「只清不缩」的可增长缓冲族
全部收口：tick 边界 16 处（轮次 20）、编码缓存桶（轮次 21）、
世界三表（轮次 22）、线程局部暂存（本轮）。
