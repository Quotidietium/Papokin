# 轮次 50：运行时驻留画像盘点（侦察轮）

- **日期**：2026-10-13
- **主题**：内存占用 · 全维度驻留画像
- **性质**：侦察轮（零生产改动，不递增版本；方法论同轮 11/12）
- **基准**：`benchmark/src/bin/residency_profile.rs`（第 50 bin）
- **数据**：`round50-residency-profile.json`（2000 实例/项，计数分配器实测）

## 动机

轮 44-49 连续六轮把各存储面压到设计地板后，需要一次系统性盘点：用**真实生产类型**（非基准内复刻）实测各面每实例驻留成本，认证「地板已达」的结论，并把剩余杠杆显式挂账，避免后续轮次在已到底的面重复探查。

## 方法

- 计数分配器（`LIVE_BYTES`/`ALLOCS` 原子累计，轮 46 起的标准量具）包裹每项构造，2000 实例取均值；
- 全部走生产构造路径：`BlockPalette::from_fn`、`BiomeContainer`、`Chest`（`LazyItemSlots<27>` + `EntityEquipment` 内嵌）、`ItemStack::new`、`TextComponent::text/translate`；
- 方块区段态数分布沿用轮 49 双臂的自然地形权重（55/17/8/12/6/2）。

## 世界规模投影

- **每千区块（24 区段 × 权重混合）**：存储面 ≈ **24.7 MB**（方块 1008.6 B/区段加权 + 群系 31.2 B/区段加权）；
- **每万实体（45% 四槽装备）**：装备面 ≈ 1.4 MB；
- **每千空箱**：≈ 0.023 MB（轮 46 前 3.3 MB → 后近零）。

## 结论

六大面（区块存储/群系/容器/装备/物品/实体构造路径）在轮 33-49 之后**均已抵达结构地板**：

1. 同质/空态全部 0 分配、16-24B 纯内联——没有可以再省的字节；
2. 非同态成本全部由**内容本征**（索引缓冲 ≥2bit/格 + 调色板行）构成，与信息论下限同阶；
3. 3bit 层负收益论证维持（轮 49）：展开/访问位移掩码成本超出 1bit/格节省的复杂度。

## 后续轮次挂账（按预估收益排序）

1. **TextComponent 驻留面**（264-276 B/例）：聊天/数据包多为瞬态，但 boss 栏、记分板标题、advancement 显示名、`custom_name` 非空实体存在长驻点；需先做生命周期画像定位驻留集合，才可立轮；
2. **NBT `custom_data` 生命周期**：方块实体/物品组件里的用户数据 `NbtCompound` 尚无逐字段画像，是剩余最大未盘点面，但改容器有存档兼容风险（红线 1），须侦察先行；
3. 区段权重再校准：当前 55/17/8/12/6/2 沿用生成器观测，真实服务器采样可再校准投影精度（不影响生产）。
