# 鞘翅烟花绑定

1.21.x 使用 Yarn 字段名 `SHOOTER_ENTITY_ID`，26.x 使用 Mojang 字段名 `DATA_ATTACHED_TO_TARGET`。旧生成器没有合并两者，服务端使用的绑定字段在 1.21.11 被标记为索引 255，序列化时不会发送。客户端因此将加速烟花当作普通烟花自由飞行。

代码生成器合并绑定、物品及发射角度字段，并保留旧公开别名。绑定烟花不再执行普通投射物的移动、惯性和碰撞；停止滑翔或插件取消加速时仍跟随目标直到寿命结束，目标离开世界则移除烟花。

物品使用入口传递实际操作的手，扣减成功后才生成烟花。烟花同步实际物品组件，按飞行时长设置寿命；发射器保留拆分出的单枚烟花组件。

回归覆盖：1.21、1.21.11、26.1、26.3 的绑定、物品和发射角度字段映射。客户端需实测主手、副手、不同飞行时长及落地前后烟花的跟随表现。
